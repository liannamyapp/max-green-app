# MAX Chat — GREEN-API

Простой веб-интерфейс чата для мессенджера **MAX**, реализованный на **React**.
Отправка и получение текстовых сообщений выполняются через сервис
[GREEN-API](https://green-api.com/max). Внешний вид повторяет чат
[web.max.ru](https://web.max.ru/).

## Возможности

- Вход по учётным данным GREEN-API (`idInstance`, `apiTokenInstance`).
- Создание нового чата по номеру телефона получателя.
- Отправка текстовых сообщений
  ([`SendMessage`](https://green-api.com/v3/docs/api/sending/SendMessage/)).
- Получение входящих сообщений через HTTP API
  ([`receiveNotification` / `deleteNotification`](https://green-api.com/v3/docs/api/receiving/technology-http-api/)),
  опрос очереди каждые 3 секунды.
- История чатов и учётные данные сохраняются в `localStorage`.

## Технологии

- React 18
- Vite 5
- Fetch API (без сторонних HTTP-библиотек)

## Требования

- Node.js 18+ и npm
- Аккаунт [GREEN-API](https://green-api.com/) с созданным и **авторизованным**
  инстансом MAX (нужны `idInstance` и `apiTokenInstance`).

## Локальный запуск

```bash
# 1. Установить зависимости
npm install

# 2. Запустить дев-сервер (откроется http://localhost:5173)
npm run dev
```

Сборка production-версии:

```bash
npm run build      # результат в папке dist/
npm run preview    # локальный предпросмотр собранной версии
```

## Как пользоваться

1. Откройте приложение в браузере.
2. Введите `idInstance` и `apiTokenInstance` из личного кабинета GREEN-API и
   нажмите **Войти**. Приложение проверит состояние инстанса
   (`getStateInstance`).
3. Нажмите **+ Новый чат** и введите номер телефона получателя
   (например, `79991234567`).
4. Напишите сообщение и нажмите **Отправить** — оно уйдёт получателю в MAX.
5. Когда получатель ответит в мессенджере MAX, ответ появится в чате
   автоматически (опрос очереди уведомлений).

## Настройка инстанса GREEN-API

Чтобы приложение получало входящие сообщения через HTTP API, в настройках
инстанса должно быть включено:

- `incomingWebhook` = `yes` (получение входящих сообщений);
- `outgoingAPIMessageWebhook` = `yes` (отражение отправленных сообщений);
- `webhookUrl` = пустая строка — используется опрос очереди, а не входящий
  вебхук.

**Приложение делает это автоматически.** После входа оно проверяет настройки
инстанса (`getSettings`) и, если получение выключено, показывает баннер с
кнопкой **«Включить получение»** (вызывает `setSettings`). После включения
инстанс перезапускается — настройки применяются в течение ~5 минут, после чего
ответы получателя начнут появляться в чате.

## Структура проекта

```
src/
  api.js                 клиент GREEN-API (sendMessage, receiveNotification, ...)
  storage.js             сохранение учётных данных и истории в localStorage
  App.jsx                состояние приложения и цикл опроса входящих
  components/
    Login.jsx            экран входа
    Sidebar.jsx          список чатов и создание нового чата
    ChatWindow.jsx       окно переписки и поле ввода
  index.css              стили в духе web.max.ru
```

## Примечание про CORS

Запросы к `https://api.green-api.com` выполняются напрямую из браузера —
GREEN-API разрешает кросс-доменные запросы, поэтому отдельный бэкенд/прокси
не требуется.
